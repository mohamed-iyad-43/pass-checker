# Password Strength Checker 🔒

This Python script evaluates the strength of a password based on various criteria and assigns a score to indicate its strength level.

## Features
- Checks password length.
- Evaluates the presence of uppercase, lowercase, numbers, and special characters.
- Penalizes repetitive characters.
- Provides a strength rating:
  - 🟢 Very Strong
  - 🟡 Strong
  - 🔴 Weak
  - 🔴 Very Weak

## How to Use
1. Clone this repository.
2. Run the script using Python:
   ```bash
   python main.py
   ```
3. Enter your password when prompted.
4. View the strength rating and score.

## Example
```bash
$ python main.py
welcome
enter your password: MyP@ssw0rd
your password is very strong 🟢
85
```
